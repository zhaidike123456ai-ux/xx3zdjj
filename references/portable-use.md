# 跨系统入口

通用Skill保存代码、依赖清单和相对路径资源。本机环境/模型/授权、个人偏好、资产库和视频项目位于Skill外。虚拟环境不直接跨系统复制，见 [环境准备](runtime.md)。

用 [项目管理](studio.md) 建立ASCII项目路径；用户输入中文路径仍正确处理。不继承原作者用户名、模型路径、应用位置或草稿ID。

Mac arm64、Mac x64、Windows x64是适配目标；其余架构以实际依赖支持为准。模拟平台测试不是目标机运行证据。字体在当前机器实际渲染后选择。

剪映能力按系统与软件版本验证，见 [剪映适配](jianying.md)。默认本机交付，不主动提示分享。用户明确要求迁移时才准备原生快照、必要素材、字幕和导入说明；系统字体、凭证和运行授权不随包分发。

私人视频仅本地处理。安装依赖/模型不等于授权上传原片、购买服务或安装额外代理Skill。
